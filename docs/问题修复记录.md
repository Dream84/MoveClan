## 问题一：创建/编辑弹窗点击内部即消失

### 现象

群组页点击「＋ 创建运动群」后，弹窗正常弹出；但点击弹窗内部的输入框或运动主题选择器（即"编辑"时），弹窗立即消失。
「我的」页的「编辑资料」弹窗存在完全相同的问题。

### 根因

弹窗容器写法存在事件冒泡缺陷：

```xml
<!-- 修复前 -->
<view class="modal-mask" wx:if="{{showCreate}}" bindtap="closeCreate">
  <view class="modal card" catchtap="">
```

`catchtap=""` 绑定了**空字符串事件处理器**。微信小程序中，空字符串不会注册任何有效拦截逻辑，因此点击弹窗内部元素产生的 `tap` 事件会继续向上冒泡，最终触达遮罩层 `modal-mask` 的 `bindtap="closeCreate"`，导致 `showCreate` 被置为 `false`，弹窗瞬间关闭。

### 修复

将空处理器改为真实空方法 `noop()`，利用 `catchtap` 拦截冒泡：

```xml
<!-- 修复后 -->
<view class="modal-mask" wx:if="{{showCreate}}" bindtap="closeCreate">
  <view class="modal card" catchtap="noop">
```

```js
noop() {},
```

### 同类问题排查

- `group-detail.wxml` 成员行 `bindtap="{{isOwner ? 'onMemberAction' : ''}}"` 动态空绑定 → 改为固定 `onMemberRowTap` + 方法内权限判断；
- 其余 `catchtap` 均绑定真实方法，无需改动。

### 涉及文件

`groups.wxml/js`、`profile.wxml/js`、`group-detail.wxml/js`

## 问题二：一直显示「没有加入任何群组」

### 现象

创建/加入群组成功后，群组页仍显示「还没有加入任何群组」；首页本周概览、最近打卡、我的页日历等同样空白。

### 根因

云开发数据库「仅创建者可读写」权限依赖记录内的 `_openid` 字段判定创建者。该字段**只有小程序端（客户端 SDK）写入记录时才会自动生成**；**云函数端 `add()` 写入的记录不会自动带 `_openid`**。

本项目 `group_members`、`checkins`、`users` 全部由云函数写入，此前未手动写入 `_openid`，导致小程序端在这些「仅创建者可读写」集合上查询时被权限规则过滤，永远查不到自己的数据。

### 修复

所有云函数写入时手动携带 `_openid: OPENID`：`login`(users)、`createGroup`(groups + group_members)、`joinGroup`(group_members)、`submitCheckin`(checkins)。

### 存量数据处理

本修复只影响修复之后新写入的数据。环境里修复前产生的旧数据（`group_members` / `checkins` 无 `_openid`）仍不可见，需二选一：
- 测试阶段：直接清空这两类数据，重新创建群/打卡；
- 保留数据：用 `database/backfill-openid.js`（控制台数据库脚本）把无 `_openid` 记录的 `_openid` 设为该记录 `openid` 字段值。

### 涉及文件

`login`、`createGroup`、`joinGroup`、`submitCheckin`、`database/*.init.json`、`README.md`

## 问题三：删除未清理数据库 / 排行不显示头像 / 登录不用微信资料

### 现象

1. 解散群组或退出群组后，`group_members`、`checkins` 等数据仍残留于数据库；
2. 排行榜与成员列表中本人及他人头像不显示（`group_members` 保存的是加入时快照，之后设置的资料不更新）；
3. 登录后未默认使用微信昵称/头像，显示为「微信用户」+ 首字占位。

### 修复

| 文件 | 修改 |
|---|---|
| `dismissGroup` | 解散时删除该群全部 `group_members`、`checkins`，并物理删除 `groups` 文档 |
| `leaveGroup` | 群主退出=解散（同上全删）；成员退出删除本人成员记录 + 本人在该群打卡记录 |
| `removeMember` | 移除成员时同步删除该成员在该群的打卡记录 |
| `getGroupRanking` / `getGroupMembers` | 改用 `users` 集合最新昵称/头像，不再依赖加入时快照 |
| `login` | 资料变更时同步更新该用户所有 `group_members` 快照 |
| `pages/index` | 未设置头像时展示「一键设置」引导条，`wx.getUserProfile` 获取微信昵称/头像并写入档案 |

## 问题四：他人头像空白 / 页面加载慢 / 群信息不可修改

### 现象与根因

1. **排行榜与成员列表其他人头像空白**：头像存为云存储 `fileID`（`cloud://...`），云存储默认权限「仅创建者可读写」，小程序端 `<image>` 直接渲染**他人**的 `cloud://` fileID 会因无权读取而空白。
2. **各页面加载慢**：每个页面 `onShow` 串行执行「登录云函数（冷启动）+ 多组数据库查询」，且每次都重新查询群列表。
3. **群名称/简介不可修改**：无对应云函数与入口。

### 修复

**头像**：`getGroupRanking`、`getGroupMembers` 返回前将成员 `cloud://` 头像 fileID 用 `cloud.getTempFileURL`（管理端，不受存储权限限制）批量转临时 URL 覆盖 `avatarUrl`。

**性能优化**：

| 优化 | 说明 |
|---|---|
| 用户缓存 | `app.js` 用户信息写入 `wx.setStorageSync`，跳过登录云函数冷启动 |
| 启动预热 | `onLaunch` 后台预热登录 |
| 群列表缓存 | `app.getMyGroups()` 缓存群列表，增删改群后 `invalidateMyGroups()` 失效重拉 |
| 并行加载 | 首页周概览+最近记录、打卡表单群列表+记录、群详情群信息+成员并行请求 |

**群信息编辑**：新增云函数 `updateGroup`（仅群主可修改名称/简介）；`group-detail` 页群主可见「编辑」按钮。

> 注意：`getTempFileURL` 临时链接有时效（约 2 小时），列表每次下拉刷新会重新获取。

## 问题五：加载中误显示无数据 / 统计与日历数据不完整（v0.5.0）

### 现象与根因

1. **打开页面加载中显示「无数据/0」**：空状态提示未加 `loading` 门控，加载完成前提前渲染。
2. **「我的」日历每月仅取 20 条**：客户端 `get()` 默认上限 20 条，超过当月的打卡日历被截断。
3. **统计加载失败卡骨架屏**：`loadStats` 失败后 `statsLoaded` 永不为真。

### 修复

- 各页面空状态提示统一加 `loading` 门控；新增全局骨架屏动画（`.sk-block`/`.sk-circle`）在加载时展示占位。
- `profile.loadMonthDays` 改为分页拉全当月数据。
- `loadStats` 用 try/finally 兜底，失败不卡骨架屏。
- 首页最近打卡分页改为按群查询 `(groupId, openid)` + 新索引；切群/快速切换用请求序号与群时效校验防乱序。

## 问题六：代码审查发现的系列问题（v0.6.0）

### 安全类

1. **排行榜缓存越权**：`getGroupRanking` 曾把「我的排名/我的数据」按群级 key 缓存，同一分钟内其他成员会拿到别人的排名数据 → 改为只缓存群列表，`myRank`/`myData` 每次按请求者即时计算。
2. **邀请码可被任意读取**：`groups` 原为「所有用户可读」，任何人可直读全部群的 `inviteCode` 绕过入群 → 权限收紧为「仅管理端可读写」，新增云函数 `getMyGroups` 读群列表，`getGroupInfo` 增加成员身份校验；客户端不再直读 `groups`/`group_members`。

### 逻辑 Bug

3. **排行榜按卡路里/时长排序失效**：排序字段名与列表字段不匹配（`calories` vs `totalCalories`），实际回落为按次数 → 增加字段映射。
4. **排名第 51 名及之后的成员 `myRank`/`myData` 错误** → 改为基于全量排序列表计算。
5. **`updateCheckin` 可把记录挪到非成员群** → 增加目标群成员校验。
6. **`createGroup` 两次写入失败无补偿**（成员写入失败留下孤儿群）→ 成员写入失败时回滚删除群文档；邀请码唯一索引冲突自动重试。
7. **`getMyStats` 带群参数时无成员校验** → 增加校验。
8. **`backfill-openid.js` 对缺 `openid` 的记录无限循环** → 增加已处理集合防死循环。

### 前端 Bug

9. **首页切群不传播到打卡表单**：`app.setCurrentGroup` 从未被调用 → 切群/加载时同步全局，且 `onShow` 后保持所选群不回跳第一个。
10. **最近打卡跨群分页错乱**：按 `openid` 分页后客户端过滤群 → 查询条件加 `groupId` + 新索引 `(groupId, openid, checkDate)`。
11. **切群/排行快速切换时旧响应覆盖新结果** → 请求序号/群时效校验。
12. **成就弹窗编辑时重复触发** → 仅新建时弹。

### 涉及文件

云函数：`getGroupRanking`、`getGroupInfo`、`getMyGroups`（新增）、`updateCheckin`、`createGroup`、`getMyStats`；
前端：`app.js`、`pages/index`、`pages/ranking`、`pages/profile`、`pages/groups`、`pages/checkin-edit`、`pages/group-detail`、`utils/api.js`；
数据库：`groups` 权限、`checkins` 索引。
