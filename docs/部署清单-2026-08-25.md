## 二、部署操作步骤

### 第 1 步：部署云函数（微信开发者工具）

对以下云函数逐个**右键 →「上传并部署：云端安装依赖」**：

| 云函数 | 说明 | 是否新增 |
|---|---|---|
| `login` | 体重回填 50、`weightKg` 读写 | 否，重部署 |
| `submitCheckin` | 运动类型白名单 17 种 | 否，重部署 |
| `updateCheckin` | 运动类型白名单 17 种 + 目标群成员校验 | 否，重部署 |
| `createGroup` | 写入回滚补偿 + 邀请码冲突重试 | 否，重部署 |
| `getMyStats` | 60s 缓存 + refresh + 群成员校验（**需云端安装依赖，含 cache 包**） | 否，重部署 |
| `getGroupMembers` | 60s 缓存 + 头像缩略 + refresh（**需云端安装依赖，含 cache 包**） | 否，重部署 |
| `getGroupRanking` | 60s 缓存 + 头像缩略 + refresh + 排序/排名修复（**需云端安装依赖，含 cache 包**） | 否，重部署 |
| `getGroupInfo` | 增加成员身份校验（防邀请码泄露） | 否，重部署 |
| `getMyGroups` | 管理端读取群列表（60s 缓存，含 cache 依赖） | **是，首次部署** |
| `updateGroup` | 群主修改群名称/简介 | **是，首次部署** |

> 注意：含 `cache` 依赖的 3 个函数，部署时必须选择「云端安装依赖」，否则运行时报 `Cannot find module 'cache'`。
> 其余函数如本地 node_modules 已存在，可选「不上传 node_modules」或「云端安装依赖」均可。

### 第 2 步：重新编译前端

今日改动涉及 `app.js`、`app.wxss`、`utils/constants.js` 及全部 6 个页面（js/wxml/wxss），需在开发者工具中**重新编译**（点击「编译」即可）。

### 第 3 步：数据库操作

**3.1 回填 `_openid`（仅当环境存在旧数据时需要）**

早期版本写入的 `group_members` / `checkins` 缺少 `_openid` 字段，会导致小程序端读不到数据（「没有加入任何群组」）。若你的云环境在此之前已有测试数据，请回填：

- 云开发控制台 → 数据库 → 「数据库脚本」→ 新建脚本 → 粘贴 `database/backfill-openid.js` 内容 → 运行
- 或直接清空这两个集合重新创建群/打卡（新数据已自动带 `_openid`）

**3.2 数据库权限与索引变更（代码审查修复，重要）**

- `groups` 集合权限由「所有用户可读」改为「仅管理端可读写」（防止邀请码被任意读取绕过入群）；客户端群列表改由云函数 `getMyGroups` 读取。
- `checkins` 集合**新建索引** `(groupId, openid, checkDate)`（首页最近打卡分页需要），`group_members` / `users` 索引不变。

**3.3 无需新建集合**

`users.weightKg` 为可选字段，无需改表。
